# SiliconFlow API Reference & Standardization Guide

为了确保本地部署（Local Backend）与云端服务（SiliconFlow）的无缝切换，我们将参考 SiliconFlow 的 API 设计规范来构建我们未来的 TTS/STT 接口。

> **Note**: This document serves as a reference for backend API development. Our goal is to maintain protocol compatibility where possible.

## Audio Services (语音服务)

### 1. Speech-to-Text (STT / 语音转文本)
*   **Function**: `create-audio-transcriptions`
*   **Description**: Creates an audio transcription.
*   **Input**: Audio file.
*   **Output**: Transcribed text.
*   **Reference**: [API Docs](https://docs.siliconflow.cn/cn/api-reference/audio/create-audio-transcriptions)

### 2. Text-to-Speech (TTS / 文本转语音)
*   **Function**: `create-speech`
*   **Description**: Generate audio from input text. The data generated by the interface is the binary data of the audio.
*   **Input**: Text, Model ID, Voice ID (optional).
*   **Output**: Audio binary stream.
*   **Reference**: [API Docs](https://docs.siliconflow.cn/cn/api-reference/audio/create-speech)

### 3. Voice Cloning & Style Management (声音克隆与管理)

#### Upload Reference Audio (上传参考音频)
*   **Function**: `upload-voice`
*   **Description**: Upload user-provided voice style, which can be in base64 encoding or file format.
*   **Use Case**: Custom voice cloning (e.g., for CosyVoice2).
*   **Reference**: [API Docs](https://docs.siliconflow.cn/cn/api-reference/audio/upload-voice)

#### Get Voice List (获取参考音频列表)
*   **Function**: `voice-list`
*   **Description**: Get list of user-defined voice styles.
*   **Reference**: [API Docs](https://docs.siliconflow.cn/cn/api-reference/audio/voice-list)

#### Delete Reference Audio (删除参考音频)
*   **Function**: `delete-voice`
*   **Description**: Delete user-defined voice style.
*   **Reference**: [API Docs](https://docs.siliconflow.cn/cn/api-reference/audio/delete-voice)
